# جنود المهدی

**مجموعه رسانه‌ای نوین**

جنود المهدی یک پروژه رسانه‌ای با هدف ایجاد بستری مدرن، ساده و کاربردی برای ارائه و انتشار محتوای رسانه‌ای است.

این پروژه به‌صورت تیمی توسعه داده شده و تلاش می‌کند در کنار ظاهر مدرن، تجربه‌ای ساده و روان برای کاربران ایجاد کند.

---

## ✨ ویژگی‌ها

* 🎨 رابط کاربری مدرن و واکنش‌گرا
* 📱 سازگار با موبایل، تبلت و دسکتاپ
* ⚡ طراحی سبک و سریع
* 📰 ساختار مناسب برای محتوای رسانه‌ای
* 🧩 معماری قابل توسعه
* 👥 توسعه به‌صورت تیمی

---

## 🛠️ تکنولوژی‌ها

این پروژه با استفاده از فناوری‌های وب توسعه داده شده است:

* HTML5

* JavaScript

> تکنولوژی‌ها و ساختار پروژه ممکن است در نسخه‌های آینده تغییر کنند.
